# Dark Fusion Launcher

A dark, customizable Android launcher built with Kotlin and Jetpack Compose.

## Current starter features

- Android Home app entry point
- Dark Fusion visual theme
- Installed-app list with search
- Launch installed apps
- Shortcut to Android default Home settings
- Customization preview screen
- GitHub Actions debug APK build

## Build

The GitHub Actions workflow builds a debug APK on every push to `main`.

The project uses JDK 17, Gradle 8.10.2, Android Gradle Plugin 8.7.3, and Kotlin 2.0.21.

## Status

Early starter version. Wallpaper selection, persistent themes, icon packs, widgets, and advanced launcher settings are planned for future updates.
